# 后续功能审批（Future Features）

> 以下功能**不得在首版直接实现**（产品定义 §二十一）。每个候选功能在开发前需生成决策卡
> （用户价值 / 开发成本 / 维护成本 / 误伤风险 / 隐私影响 / 商店审核影响 / 账号风控影响 / 推荐与否），
> 经用户明确批准后方可进入开发范围。

| 功能 | 初步评估（非决策） | 主要顾虑 |
|---|---|---|
| AI 语义识别 / 文本分类 | 高误伤、隐私与审核风险 | 需要远程模型或本地大模型，v1 明确排除 |
| 图片 OCR / 图片广告识别 | 成本高、误伤高 | 需要视觉能力与更多权限 |
| 云端账号评分 / 云风控 | 数据外发 | 违反「不上传用户数据」原则 |
| 社区共享黑名单 / 远程规则订阅 | 审核与供应链风险 | 远程内容 = 远程代码风险；第三方数据质量不可控 |
| 跨设备同步 | 需账号系统/服务端 | v1 无服务端 |
| 批量举报 / 大规模导入 UID 后立即批量举报 | 账号风控高风险 | 违反保守限流与单一用途 |
| 页面后台自动遍历 | 越权与风控风险 | 只处理用户看到的页面 |
| 无内容依据的账号举报 | 违反举报双条件 | 误伤严重 |
| 直播间 / 专栏 / 番剧 / 搜索结果 / 用户空间 | 成本与稳定性 | 可作为低成本附加兼容页面单独评估 |
| Firefox / Safari / 移动端 | 平台成本 | 需要 WXT 多浏览器适配评估 |
| 付费订阅 / 服务端后台 / 用户信誉分 / 举报排行榜 | 违背单一用途与本地优先 | 明确排除 |
| 网络层过滤（Vista 思路） | 更抗虚拟滚动但需 webRequest | 权限最小化冲突，需单独论证 |
